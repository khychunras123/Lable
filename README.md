# 📦 ACC Store - Delivery Label & Order Management System

ប្រព័ន្ធគ្រប់គ្រងការបញ្ជាទិញ និងបោះពុម្ពស្លាកដឹកជញ្ជូន 80x60mm Thermal Sticker Label សម្រាប់អាជីវកម្ម Online / E-commerce នៅកម្ពុជា។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

- **🏷️ ទម្រង់ស្លាកដឹកជញ្ជូន 80x60mm Landscape (Thermal Label)**: រចនាបទស្អាត ត្រឹមត្រូវតាមទំហំក្រដាសកម្ដៅ 80x60mm មាន Header ឈ្មោះហាង, QR Code, ព័ត៌មានអតិថិជន, អាសយដ្ឋានជាភាសាខ្មែរ, ស្លាក Watermark PAID/COD, និងប្រអប់តម្លៃ។
- **💬 ទម្រង់ Telegram Bot Receipt**: បង្ហាញទម្រង់វិក្កយបត្របែប Telegram Bot ជាមួយប៊ូតុងចុចទាក់ទងអតិថិជន និងព្រីន Label ផ្ទាល់។
- **📋 Smart Telegram Text Parser**: Copy អត្ថបទ Order ពី Telegram មក Paste ចូល រួច System នឹងបំប្លែងទិន្នន័យចូល Table ដោយស្វ័យប្រវត្តិ។
- **📊 Interactive Editable Table**: តារាងទិន្នន័យអាច Search, Filter តាមស្ថានភាពបង់ប្រាក់ និងក្រុមហ៊ុនដឹកជញ្ជូន (VET, J&T, Flash, Capitol)។
- **🖨️ Batch Print Engine**: អាចបោះពុម្ពស្លាកម្តងមួយ ឬជ្រើសរើសជាច្រើន (Batch Print) ទៅកាន់ម៉ាស៊ីន Thermal Printer ដោយគ្មានបញ្ហា Margin។
- **💾 Local Storage & CSV Export**: រក្សាទុកទិន្នន័យលើ Browser ដោយស្វ័យប្រវត្តិ និងអាច Export ជាឯកសារ CSV/Excel។

---

## 🚀 របៀបប្រើប្រាស់ (How to Run)

គ្រាន់តែបើកឯកសារ `index.html` លើ Browser ណាមួយ (Google Chrome, Microsoft Edge, Safari) ជាការស្រេច ដោយមិនចាំបាច់ដំឡើងអ្វីបន្ថែមឡើយ។
